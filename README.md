# Facil Dent — Landing page

Página web de la clínica dental Facil Dent (San Martín de Porres, Lima): especialidades, staff médico, promociones, ubicación y formulario de citas que envía la solicitud por WhatsApp.

## Tecnologías
HTML · CSS · JavaScript (sin frameworks)

## Archivos
- `index.html` — estructura y estilos de la página.
- `app.src.js` — lógica: formulario de citas a WhatsApp e interacciones de la página.

> Las imágenes y videos de la clínica no se incluyen en este repositorio por privacidad.
